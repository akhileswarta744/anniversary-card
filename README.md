## ✨ Features

- 💬 **Live P2P Chat**: Real-time messaging between Karnataka & Kerala directly in the terminal via encrypted WebRTC.
- 💸 **Love-Chain Payments (`pay`)**: Send `$KISSES`, `$HUGS`, `$LOVECOIN`, with animated cryptographic receipts.
- ⏳ **5-Year Milestone Uptime (`uptime`)**: Live SLA counter showing 5 years of uptime with 0 downtime.
- 🔓 **Decrypted Love Letter (`decrypt`)**: 4096-bit RSA cipher scramble animation revealing the secret anniversary letter.
- 🎟️ **Romantic Coupon Vault (`coupons` / `redeem`)**: Redeem coupons for candlelight dinner, massages, breakfast in bed, etc.
- 💍 **Sudo Vow Renewal (`sudo marry-again`)**: Launches synchronized fireworks and fanfare across both devices simultaneously.
- 🎵 **Web Audio API Synth Engine**: 8-bit romantic synthwave BGM and authentic mechanical keystroke SFX.
- 🎨 **4 Themes**: Neon Cyberpunk, Matrix Green, Retro Amber, Vaporwave Glow.
